# ORTEVIA — Chaque mouvement compte.

Site vitrine statique en français. Ouvrir `dist/index.html` ou servir le dossier `dist` avec un serveur HTTP statique. Aucun outil de compilation ni dépendance n’est nécessaire.

14 produits, filtres accessibles, mise en page adaptative, contact WhatsApp avec messages préremplis. Le site ne réalise aucun paiement et n’envoie aucun message automatiquement.

## Confidentialité

Ne jamais ajouter de PDF tarifaire, tarifs chiffrés, marges, codes ou montants de remboursement au dépôt ou au site. Les images produits sont extraites individuellement du catalogue. Les données de présentation se trouvent dans `dist/products.js`.

## Avant ouverture publique

Compléter et valider l’adresse légale, le numéro IDE, le responsable de publication, les coordonnées juridiques de l’hébergeur et les détails de traitement des données dans les textes légaux de `dist/app.js`. Vérifier les droits sur les visuels fournis et les coordonnées commerciales.
